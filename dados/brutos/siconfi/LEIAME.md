# Dados brutos do Siconfi (DCA)

Declarações de Contas Anuais (DCA) das 9 capitais do Nordeste, 2014–2025, exatamente como devolvidas pela API do Tesouro Nacional
(https://apidatalake.tesouro.gov.br/ords/siconfi/tt/dca). Nome dos arquivos: `dca_<anexo>_<municipio>_<ano>.csv`
(`receitas` = Anexo I-C; `despesas_natureza` = Anexo I-D; `despesas_funcao` = Anexo I-E). Coleta: `codigo/01_coleta_siconfi.py`.
